# RemoteDesk

โปรแกรมรีโมตควบคุมหน้าจอสำหรับ Windows ใช้งานคล้าย AnyDesk ไฟล์เดียว ไม่ต้องติดตั้ง และไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง สองเครื่องเชื่อมต่อกันผ่านอินเทอร์เน็ตแบบ P2P (ใช้ [iroh](https://github.com/n0-computer/iroh))

## ความสามารถ

- ID 10 หลัก ผูกกับเครื่อง ไม่เปลี่ยนแม้ลบแล้วติดตั้งใหม่
- เห็นสถานะออนไลน์ของเครื่องที่บันทึกไว้
- ควบคุมเมาส์และคีย์บอร์ด รวมถึงคีย์ลัด Ctrl/Shift/Alt
- คัดลอกและวางข้อความหรือไฟล์ข้ามเครื่อง
- หน้าต่างให้เครื่องปลายทางกดรับ และเลือกสิทธิ์ (ควบคุม / คลิปบอร์ด / ไฟล์)
- ตั้งรหัสผ่านเองได้ และเลือกให้เข้าอัตโนมัติได้
- แชทระหว่างสองเครื่อง
- บันทึกประวัติการเข้าถึง และล็อกชั่วคราวเมื่อใส่รหัสผิดหลายครั้ง
- เปิดพร้อม Windows, ย่อไปอยู่ที่ System Tray
- อัปเดตอัตโนมัติจาก GitHub Releases (ตรวจลายเซ็นก่อนติดตั้ง)

## ดาวน์โหลด

ดาวน์โหลด `RemoteDesk.exe` จากหน้า [Releases](https://github.com/GoneSeeder/RemoteDesk/releases/latest) แล้วเปิดใช้งานได้เลย โปรแกรมจะขอสิทธิ์ผู้ดูแลระบบเพื่อควบคุมหน้าต่างที่รันแบบ admin ได้ (เช่น Task Manager)

ไฟล์ยังไม่ได้เซ็นด้วยใบรับรอง Windows อาจแสดงคำเตือน SmartScreen ให้กด "More info" แล้ว "Run anyway"

## วิธีใช้

1. เปิดโปรแกรมทั้งสองเครื่อง
2. นำ ID 10 หลักของเครื่องปลายทางมาใส่ แล้วกดเชื่อมต่อ
3. เครื่องปลายทางกดรับ หรือใส่รหัสผ่านที่ตั้งไว้

## Build จากซอร์ส

ต้องมี Rust (stable) บน Windows

```bash
cargo build --release
```

ไฟล์อยู่ที่ `target/release/RemoteDesk.exe`

## การปล่อยเวอร์ชัน

แก้ `version` ใน `Cargo.toml` แล้ว push tag `vX.Y.Z` GitHub Actions จะ build, เซ็น และสร้าง Release ให้ (ต้องตั้ง secret `REMOTEDESK_SIGNING_KEY` ไว้)

## ข้อควรรู้

- รองรับเฉพาะ Windows
- ยังส่งปุ่ม Windows และ Alt+Tab ไปเครื่องปลายทางไม่ได้
- ไม่มีระบบเสียง
- ไม่แนะนำให้ใช้กับเซิร์ฟเวอร์สำคัญ
